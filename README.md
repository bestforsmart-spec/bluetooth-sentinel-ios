# BT Sentinel

Минимальный iPhone-прототип для мониторинга новых BLE-устройств рядом.

## Что делает

- Сканирует Bluetooth Low Energy advertising через CoreBluetooth.
- Молча запоминает впервые увиденные BLE-устройства как известные.
- Подает сигнал только при признаках сближения устройства; сигнал сближения отличается от старого сигнала первого обнаружения.
- Показывает имя, RSSI, примерную дистанцию в метрах, ориентировочное направление, локальный CoreBluetooth UUID и краткие advertising-данные.
- Показывает предполагаемый тип устройства: телефон, компьютер, дрон, аудио, часы/браслет, трекер, авто, клавиатура/мышь, IoT/датчик или неизвестно.
- Позволяет вручную добавить устройство в список доверенных.
- В полевом режиме сканирует без service-фильтра, с duplicate advertising packets, молча добавляет новые устройства в список известных и предупреждает только при признаках приближения.
- В обычном режиме новые устройства также добавляются в список известных без сигнала.
- Автоматически убирает устройство из текущего списка, если сигнал не обновлялся 60 секунд.
- Поддерживает работу BLE-сканирования в фоне через `bluetooth-central` и показывает локальное уведомление при новом устройстве, если приложение свернуто.
- Поддерживает беззвучный режим `Беззвучно: вибро`, когда вместо звука используется вибросигнал.
- Сохраняет базу доверенных и тихих устройств в UserDefaults.

## Ограничения iOS

- iPhone-приложение не видит "вообще все" Bluetooth-устройства. CoreBluetooth обнаруживает BLE-периферии, которые рекламируются в эфире.
- Полевой режим не увеличивает физическую мощность Bluetooth-антенны iPhone; он убирает программное успокоение и использует максимально широкое BLE-сканирование, доступное приложению.
- Приближение определяется по устойчивому усилению RSSI/падению расчётной дистанции. В лесу, рядом с телом, металлом, влажностью и рельефом RSSI может прыгать, поэтому это сигнал-подсказка, а не точное измерение.
- iOS не дает приложению MAC-адрес устройства; используется локальный `CBPeripheral.identifier`.
- Тип устройства определяется приблизительно по имени, BLE service UUID и manufacturer data. Многие BLE-устройства скрывают имя или маскируются, поэтому это подсказка, а не гарантия.
- Дистанция считается приблизительно по RSSI и зависит от стен, тела, антенн, мощности передатчика и помех.
- Направление не приходит из Bluetooth напрямую. Приложение использует компас iPhone и запоминает, в каком направлении сигнал устройства был сильнее. Для оценки направления медленно повернитесь с телефоном на 360 градусов.
- Фоновое сканирование ограничено системой. `bluetooth-central` включен, но iOS может реже отдавать события в фоне; надежнее держать приложение активным на экране, когда нужна максимальная чувствительность.
- Для фоновых предупреждений разрешите уведомления. Беззвучный режим использует вибрацию, но iOS может ограничивать прямой вибросигнал, когда приложение уже глубоко приостановлено.
- Симулятор не подходит для проверки реального Bluetooth-сканирования. Нужен физический iPhone.

Официальные ориентиры Apple:

- Core Bluetooth: https://developer.apple.com/documentation/corebluetooth/
- `scanForPeripherals`: https://developer.apple.com/documentation/corebluetooth/cbcentralmanager/scanforperipherals(withservices:options:)
- Background Processing: https://developer.apple.com/library/archive/documentation/NetworkingInternetWeb/Conceptual/CoreBluetooth_concepts/CoreBluetoothBackgroundProcessingForIOSApps/PerformingTasksWhileYourAppIsInTheBackground.html

## Запуск

1. Откройте `BluetoothSentinel.xcodeproj` в Xcode.
2. В target `BluetoothSentinel` выберите свою команду подписи.
3. Запустите на физическом iPhone.
4. Разрешите доступ к Bluetooth.
5. Нажмите `Доверять текущим`, когда окружение считается нормальным.

После этого BLE-устройство должно вызвать звуковой сигнал только при признаках сближения.
