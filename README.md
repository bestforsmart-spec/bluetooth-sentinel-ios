# BT Sentinel

**BT Sentinel 1.0 beta** - полевой iPhone-инструмент для наблюдения за BLE-устройствами рядом и предупреждения о новых появлениях или устойчивом сближении.

## Коротко

Приложение слушает Bluetooth Low Energy advertising через CoreBluetooth, показывает компактную сигнальную таблицу устройств, сглаживает RSSI и подаёт разные короткие сигналы для двух событий: новое устройство после тихого старта и подтверждённое сближение.

## Функции

- Тихий старт: при первом развёртывании окружение собирается без звука.
- Новые устройства: после тихого старта неизвестный BLE UUID поднимается вверх, отображается как новый и даёт короткий сигнал + вибро.
- Сближение: тревога с другим сигналом + вибро только при устойчивом росте сигнала за окно анализа; звук приближения - три коротких низких импульса и один более длинный высокий.
- Фильтрация RSSI: медиана, отсечение выбросов, deadband 3 dBm и обновление UI раз в секунду.
- Автопереход в известные: новое устройство становится известным через 5 минут стабильного наблюдения, если не было сближения.
- Компактный список: RSSI, примерная дистанция, тип устройства, сила сигнала и тренд.
- Детальная карточка: история сигнала, advertising-данные, идентификатор и действия доверия.
- Тёмная и светлая темы.
- Фоновое уведомление для важных событий, насколько это разрешает iOS.

## Важно

BT Sentinel не делает iPhone радионевидимым полностью и не усиливает физическую антенну. iOS-приложение может только слушать доступные BLE advertising-пакеты; Wi-Fi, AirDrop, Hotspot, MAC-адреса, сырые частоты и SDR-режим находятся вне контроля приложения.

RSSI не является точной дистанцией. Тело, рельеф, влажность, металл, положение телефона и мощность передатчика могут давать скачки. Поэтому приложение использует устойчивые фильтры и сообщает о сближении только после накопления признаков.

## Запуск

1. Откройте `BluetoothSentinel.xcodeproj` в Xcode.
2. Выберите физический iPhone и команду подписи.
3. Запустите приложение и разрешите Bluetooth/уведомления.
4. Дождитесь тихого старта.
5. Держите приложение активным на экране для максимальной чувствительности.
